---
name: Object driver assignments
description: Where administrators create and change the driver assigned to an object.
---

Create and change the driver assigned to an object only in the «Объекты» section. Do not expose object-assignment controls or assignment-status columns in «Пользователи».

**Why:** An assignment belongs to the object. Keeping a second editor on the user list creates two competing workflows and makes «Не закреплены» ambiguous.

**How to apply:** Use the driver selector when creating an object and the inline driver selector or object edit page for later changes. Keep «Пользователи» focused on personal details, roles, and section access.
