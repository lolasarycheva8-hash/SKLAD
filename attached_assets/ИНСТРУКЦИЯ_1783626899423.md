# Бот развоза в Telegram — инструкция

Бот делает три вещи:
- **Водитель** получает утром список своих точек на сегодня и жмёт кнопку **«Доставил ✅»** — это и есть «факт».
- **Менеджер** вечером получает: что выполнено сегодня по его магазинам + план на завтра (с адресами).
- **Руководитель** раз в 3 дня получает короткую сводку: **План / Факт / Отклонение** и список просроченных.

Бот сам считает отклонение = доставка, у которой дата прошла, а отметки «Доставил» нет.

---

## Что внутри папки
- `bot.py` — сам бот (запускаете его).
- `config.py` — настройки (токен, имя руководителя, время рассылок).
- `requirements.txt` — список библиотек.
- `График_развоза.xlsx` — ваш график (положите сюда и назовите именно так).
- `ИНСТРУКЦИЯ.md` — этот файл.

---

## Шаг 1. Создать бота в Telegram (2 минуты)
1. В Telegram найдите **@BotFather**.
2. Отправьте `/newbot`, придумайте имя и username (заканчивается на `bot`).
3. BotFather пришлёт **токен** — длинную строку вида `123456:AAH...`. Скопируйте её.

## Шаг 2. Установить Python
- Скачайте Python 3.11+ с https://python.org → при установке поставьте галочку **«Add Python to PATH»**.
- Проверка: откройте командную строку (Windows: «cmd») и введите `python --version`.

## Шаг 3. Положить файлы
- Скопируйте всю папку с ботом в удобное место.
- Положите туда ваш Excel и **переименуйте в `График_развоза.xlsx`**.
  (Листы внутри должны называться `Москва` и `МО (остальное)` — как сейчас.)

## Шаг 4. Установить библиотеки
В командной строке зайдите в папку бота и выполните:
```
cd путь\к\папке\delivery_bot
pip install -r requirements.txt
```

## Шаг 5. Вписать настройки
Откройте `config.py` обычным «Блокнотом» и заполните:
- `BOT_TOKEN` — токен из шага 1.
- `HEAD_NAMES` — имя руководителя (как он назовётся боту), например `["Иван"]`.
- При желании поменяйте время рассылок (`MANAGER_REPORT_TIME` и т.д.).

## Шаг 6. Запустить
```
python bot.py
```
Если видите «Бот запущен» — всё работает. **Пока это окно открыто — бот живёт.** Закрыли окно — бот остановился (как это сделать постоянным — см. в конце).

---

## Шаг 7. Регистрация сотрудников (один раз каждому)
Каждый водитель / менеджер / руководитель:
1. Открывает вашего бота в Telegram, жмёт **/start**.
2. Пишет своё **имя так, как оно стоит в графике** (например: `Станислав`, `Павел`).
3. Бот отвечает, кем он зарегистрирован.

> Бот узнаёт людей по имени из графика. Telegram-ник заполнять заранее не обязательно — он подтянется сам при регистрации.

---

## Как пользоваться

**Водитель**
- `/today` — точки на сегодня, у каждой кнопка «Доставил ✅».
- Утром бот сам присылает список (время в `DRIVER_PUSH_TIME`).

**Менеджер**
- `/mine` — факт за сегодня + план на завтра по своим магазинам.
- Вечером приходит автоматически (`MANAGER_REPORT_TIME`).

**Руководитель**
- `/summary` — сводка в любой момент.
- Раз в 3 дня приходит автоматически (`HEAD_REPORT_TIME`, `HEAD_REPORT_EVERY_DAYS`).

**Команды администратора (для вас)**
- `/reload` — перечитать `График_развоза.xlsx` после правок (отметки о доставке сохраняются).
- `/export` — выгрузить Excel с текущим фактом (статус, кто, когда).
- `/report_managers` — разослать отчёт менеджерам прямо сейчас (для теста).
- `/report_head` — отправить сводку руководителю прямо сейчас.
- `/whoami` — проверить, кем вы зарегистрированы.

## Важные заметки
- **Жёлтые строки без менеджера** в графике в отчёты менеджерам не попадут (некому слать) — они видны только в сводке руководителя как часть плана. Заполните менеджера — и они подхватятся после `/reload`.
- **Столбец «Перевозчик / Водитель»** сейчас заполнен почти только по «Павел». Водитель видит лишь те точки, где в этом столбце стоит его имя. Чтобы все водители получали свои списки — заполните этот столбец и сделайте `/reload`.
- **Меняете график на новый месяц?** Просто обновите `График_развоза.xlsx` и выполните `/reload`. Уже сделанные отметки «Доставлено» сохраняются (привязка по «магазин + дата»).
- **Чтобы бот работал круглосуточно** без вашего включённого компьютера — арендуйте недорогой VPS (например, у российского хостера) и запускайте `bot.py` там. По запросу подготовлю отдельную инструкцию по серверу.
- **MAX вместо Telegram** — логика та же; когда понадобится, перенесём отправку сообщений на MAX-бота.

---

## Если что-то не так
- «Файл не найден» → проверьте, что Excel лежит рядом и назван `График_развоза.xlsx`.
- «Не нашёл такое имя» при регистрации → имя должно совпадать с тем, что в столбце «Менеджер» / «Водитель».
- Не приходят рассылки → проверьте, что человек прошёл `/start`, и что бот запущен в нужное время (часовой пояс — `TIMEZONE` в config).
